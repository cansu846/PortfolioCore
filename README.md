<h1 align="center">🧾 Personal Portfolio Web Application</h1>

<p align="center">
  <em>A modern, responsive CV website built with ASP.NET Core 6.0 and a full tech stack.</em>
</p>

---

## 🚀 Technologies Used

<ul>
  <li><b>ASP.NET Core 6.0 (Web API & MVC)</b> – Application framework and backend logic</li>
  <li><b>MSSQL</b> – Relational database</li>
  <li><b>Entity Framework Core & LINQ</b> – ORM and data access layer</li>
  <li><b>HTML, CSS, Bootstrap</b> – Frontend layout and styling</li>
  <li><b>JavaScript</b> – Dynamic interactions and enhanced UX</li>
</ul>

---

## 🎯 Project Purpose

This project is designed to <b>showcase my software development skills</b> and present my resume in a web-based, interactive format. Rather than a static PDF, this dynamic CV application delivers a richer and more engaging professional profile.

---

## 🛠️ Features

- ✅ Sections for personal info, education, experience, and skills  
- ✅ Responsive design (mobile-friendly)  
- ✅ CRUD operations  
- ✅ (Optional) Admin panel for easy updates  

---
## 🔎 Portfolio Filtering Feature

<div style="border: 1px solid #ddd; border-left: 6px solid #007bff; padding: 16px; background-color: #f9f9f9; font-family: Arial, sans-serif;">
  <h3 style="margin-top: 0; color: #007bff;">📂 Filter Portfolios by Category</h3>
  <p style="color: #333;">
    This web application allows users to filter portfolio items by category using an intuitive UI. When a category (e.g., <em>App Programming</em>, <em>AI</em>) is selected, the corresponding items are fetched and displayed dynamically via <strong>AJAX</strong>, without a page refresh.
  </p>
  <p style="color: #333;">
    This feature enhances the user experience by making it easy to browse different sections of the portfolio based on user preferences, without reloading the entire page.
  </p>
</div>
